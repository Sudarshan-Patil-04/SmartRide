**SmartRide – Smart Ride Booking & Fleet Management System**

SmartRide is a full-stack ride-booking and fleet management application designed to connect customers, drivers, and administrators through a seamless and efficient platform.

The system provides secure authentication, ride booking, driver management, real-time ride tracking, and role-based access control.

**Key Features**
- User registration and login with JWT authentication.
- Role-based access for Customers, Drivers, and Admins.
- Ride booking and ride management.
- Driver availability (Online/Offline).
- Real-time driver location tracking.
- Ride status updates and ride history.
- Admin dashboard for managing users and drivers.
- RESTful API integration.

**Technology Stack**
- Frontend: React.js, Tailwind CSS
- Backend: Java, Spring Boot
- Database: MongoDB
- Authentication: Spring Security, JWT
- Real-time Communication: WebSocket, STOMP, SockJS
- Maps: Leaflet, OpenStreetMap, OSRM

**Project Goal**

To develop a scalable and user-friendly ride-booking platform that simplifies transportation management and provides real-time connectivity between customers and drivers.
